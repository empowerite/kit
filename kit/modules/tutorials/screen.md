Every kittui screen stacks the same parts. An [app](kittui:welcome/terms/application), such as [Flow](kittui:flow),
looks like this:

```text
  = kit flow · - owner/repo                 🔎 /search   ← menu bar
  ➊╶───────────────╮➁╶────────────────╮                  ← tab bar
  │ 🎫 issues  7 : │  🔀 changes  3   │
  ╵                ╰──────────────────╰──
  ▾ source 7                       All Issues ▼          ← control line
      id   age  title                                    ← header
      ·────·────·──────────────                          ← rule
    ▸ #45   2h  🎫 kit flow is the…                      ← rows
    ▸ #46   2d  🎫 A noun lists…
 = menu - workspace / search ? legend │ ⇥·⇧⇥ tab         ← status bar
```

## The parts

- [**Menu bar**](kittui:tutorials/menu-bar), the first line: the kit menu, the screen's name, the
  [workspace](kittui:welcome/terms/workspace), and the [search](kittui:tutorials/search).
- [**Tab bar**](kittui:tutorials/tab-bar): one tab per [stage](kittui:welcome/terms/stage). Apps only.
- [**Control line**](kittui:tutorials/control-line): how the [rows](kittui:tutorials/rows) are grouped, and the preset
  they are set as.
- **The view**: the header, its rule, and the [rows](kittui:tutorials/rows). Most of the screen.
- [**Status bar**](kittui:tutorials/status-bar), the last line: the keys that work right now.
- [**Legend**](kittui:tutorials/legend): floats over the rows and names every glyph on the screen. Apps only.

## Five keys to start

- `=`  the [kit menu](kittui:tutorials/menu-bar): every screen, Settings…, Quit
- `/`  [search](kittui:tutorials/search)
- `?`  [the legend](kittui:tutorials/legend)
- `esc`  back out one step. It never quits.
- `⌃Q`  quit

Every action also works with a plain click.
