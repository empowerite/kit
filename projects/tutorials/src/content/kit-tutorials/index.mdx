kit's tutorials are web pages, one for each feature. Each is tagged with who it is for: someone just starting, someone
who works in kit's terminal UI, or someone who maintains a repository's kit.

## Opening a tutorial

Run `kit tutorials` in a repository with kit installed. It shows a button for each tutorial, filtered by audience if
you like, and a button opens its tutorial here, in your browser. Nothing on these pages runs a command for you: a
tutorial shows commands, and you choose where to run them.

## One site for each line of kit

Every 0.4.x release of kit opens the tutorials written for 0.4. A passage that a patch release made true is marked
with the release it arrived in.

<Since version="0.1.0">
When kit opens a page, it names its own version in the address, so the page can tell you when a passage needs a newer
kit than yours. A page opened without it, from your browser's history say, shows the marks plainly.
</Since>

The navigation above leads to what is new in this line of kit and to the changelog of each of its releases.
